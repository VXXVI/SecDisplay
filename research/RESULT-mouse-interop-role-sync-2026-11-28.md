# 面板统一、鼠标互通、角色跟随与过渡层

日期：2026-11-28

## 背景

针对四类反馈：

1. Mac 与 Windows 控制面板视觉不统一。
2. 副屏「晃动找光标」缩小时机不对。
3. 希望 Windows 物理鼠标能直接操控 macOS。
4. macOS 切换主/副屏后 Windows 不会自动跟随；切换期间黑屏；偶发鼠标位置重置。

## 结论

### 1. 面板视觉

Windows 面板保留 960 宽三列信息卡结构，但角色/显示方式改为与 Mac 一致的
「两行大选择卡 + 标题/副标题 + 选中勾」，卡片圆角 10、弱描边、小节标题改为
「文字 + 右侧发丝线」，字号阶梯上调到 13/10/10/9。常驻开关
「鼠标互通」「跟随 Mac 自动切换」放在角色卡右侧空白区，不挤占接收端开关行。

Mac 面板本身已是该结构，改动集中在 Windows 自绘代码：
`PaintControlPanel`、`LayoutPanelControls`、`DrawPanelButton`、`PanelTheme::Ensure`。

### 2. 晃动找光标时序

旧实现：GROW 140ms → 停手后 HOLD 350ms → SHRINK 220ms，合计约 570ms；
且任何 0x03 包（包括亚像素死区产生的同坐标消息）都会无条件续期 HOLD。

新实现：

- GROW 90ms，HOLD 140ms，SHRINK 170ms。
- 只有屏幕坐标真的变化才续期 HOLD。
- 网络线程观察到 0x03 位置变化也计入 HOLD，避免窗口失焦/本地让位时误判静止。
- SHRINK 期间检测到 ≥3dp 的新移动，直接从当前倍率回到 GROW。
- 放大叠加层显示期间冻结稳态光标基准，避免中途换图导致几何突跳。
- Mac 发送端不再「静止 2.2 秒后补发原生大图」：瞬态放大图一律跳过，
  只有持续静止 5 秒仍是大图才认定为永久大指针。这样 Windows 叠加层缩回后
  不会再来一次迟到的大图。

参考：Apple Support「Shake mouse pointer to locate」；实际手感反馈显示
macOS 停止后约 0.1s 开始回落，但持续轻微移动会保持放大。

### 3. 鼠标互通

现状：Mac 主控时，Mac 光标绝对坐标 `0x03` 驱动 Windows 系统光标；
Windows 本机鼠标在副屏窗口内移动时，已经通过 `0x04` 回传并由 Mac 注入。
Windows 主控时，`Ctrl+Alt+K` 走 `0x0A/0x0B/0x0C` 相对 KVM。

本次补齐可用性与边界：

- 面板新增「鼠标互通」开关（`mousebridge`）。
- 本机 Raw Input 活动后的让位窗口由 60ms 提升到 350ms，减少远端坐标把
  本机指针立刻拽回造成的跳动。
- Mac 注入回声环从 8 槽/80ms 扩到 16 槽/150ms，降低双向自激概率。
- 光标离开副屏时不再把坐标清成 NaN，保留最后有效位置；会话头尺寸变化时
  按新旧基准等比重映射，而不是直接丢弃位置。

### 4. 角色跟随

Windows 接收端收到 Mac 接收端的 `0x7E role=1` 或 `0x7F reason=2` 时，
说明 Mac 已切为副屏，Windows 自动切为主控；
Windows 主控端收到 Mac 主控端的 `0x7F reason=1` 时，说明 Mac 已切为主屏，
Windows 自动切回副屏。切换有 8 秒冷却，Mac 始终是角色基准。

### 5. 切换过渡层

Windows 接收端新增独立分层窗口：

- 从未收到首帧：不透明品牌深蓝 + 阶段文字。
- 断线/无信号：保留最后一帧，压暗到约 84% 不透明度，并显示状态文字。
- 首帧真正 Present 后自动隐藏。
- 窗口 `WS_EX_TRANSPARENT`，不拦截鼠标；DPR/移动/尺寸变化时跟随窗口。

Mac 接收端在断线时保留最后一帧，叠加 62% 黑色压暗层与等待文字，
下次首帧到达后收起。

## 验证

- macOS：`swiftc -O Sources/main.swift Sources/AppUI.swift Sources/MacReceiver.swift` 通过。
- Windows：MinGW-w64 14 全量链接通过（含 `ICodecAPI` UUID 特化修正）。
- 未能实机运行 Windows 端（当前 mac 主机无 Windows），需要在真机上回归：
  角色双向切换、鼠标互通、断线压暗、首帧收起、晃动时序。

## 风险

- 角色跟随依赖 0x7E/0x7F 语义；旧版对端仍会走原有冲突提示，不会自动切换。
- 保留最后一帧压暗必须配合明确文字，否则可能被误认为当前画面。
- 动效时序为常量，若目标机刷新率极低（<30Hz）观感会变慢。
