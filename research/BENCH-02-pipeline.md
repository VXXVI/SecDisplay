# 实测数据：完整管线各段性能

测试环境：MacBook Pro M1 Pro / 16GB / macOS 27.2 (26B123)
屏幕录制权限：已授权
测试日期：2026-11-05

---

## 一、虚拟屏

| 项目 | 实测值 |
|---|---|
| 创建耗时 | 327 ~ 787 ms（首次较慢，后续约 330 ms）|
| 上线延迟 | 0 ms（applySettings 返回后立即可用）|
| 销毁延迟 | 200 ms 内从系统消失 |
| 稳定性 | 连续创建/销毁 10 次以上无残留 |

### HiDPI 配置规则

| 背板 maxPixels | 模式逻辑尺寸 | 结果 |
|---|---|---|
| 2560x1600 | 2560x1600 | scale 1.0，1:1 |
| 2560x1600 | 1280x800 | 系统忽略，回落 1:1 |
| 5120x3200 | 2560x1600 | **scale 2.0，真 Retina** |

结论：**HiDPI 由「背板 = 逻辑 x2」决定，不是 hiDPI 开关。**

## 二、编码器

输入：合成桌面内容，每帧都不同。H.264 High，低延迟模式，无 B 帧，目标 80 Mbps。

| 分辨率 | 帧率 | 码率 | 编码调用耗时/帧 |
|---|---|---|---|
| 1920x1080 | 59.0 fps | 19.0 Mbps | 0.112 ms |
| 2560x1600 | 59.8 fps | 20.8 Mbps | 0.078 ms |
| 3024x1964 | 52.5 fps | 17.9 Mbps | 0.099 ms |
| 3840x2160 | 38.7 fps | 15.5 Mbps | 0.120 ms |

**结论：编码器不是瓶颈。** 每帧只有 0.1ms 左右，60fps 预算 16.6ms，余量 100 倍以上。

4K 掉到 38fps 是测试代码的 CPU 重绘开销，不是编码器能力问题。

## 三、采集（ScreenCaptureKit）

### 静态桌面

| 场景 | 帧率 | 说明 |
|---|---|---|
| 无窗口，纯壁纸 | 12~13 fps | SCK 按需降帧，这是设计行为，省电 |

### 有动画内容

| 场景 | 帧率 | 码率 | 说明 |
|---|---|---|---|
| CALayer 动画（方块移动+透明度脉动）| **54.4 fps** | 0.4 Mbps | 330 帧全部采集并编码 |

**结论：有内容变化时能跑到 54fps 以上。** 静态时降帧完全正常。

### 抓屏正确性验证

用 SCK 抓虚拟屏并存成 PNG 检查，确认抓到的是真实的完整桌面：
- 分辨率 2560x1600，与设定一致
- 包含菜单栏、Dock 区域、其他应用窗口
- macOS 完全把虚拟屏当作一等公民显示器

## 四、各段延迟预算（理论推算）

按 2560x1600@60fps 计算：

| 阶段 | 耗时 | 依据 |
|---|---|---|
| 合成完成 → SCK 抓到帧 | 2 ~ 5 ms | 社区实测 4~13ms，取乐观值 |
| 编码提交 | 0.1 ms | 本次实测 |
| 编码硬件流水线 | 3 ~ 8 ms | 硬件编码器固有延迟 |
| 网络传输（千兆有线）| 0.2 ~ 1 ms | 单程 |
| 解码（MF 硬解）| 3 ~ 8 ms | 同类硬件水平 |
| 呈现 | 1 ~ 16 ms | 不垂直同步可低至 1ms，垂直同步最坏 16.6ms |
| **合计** | **约 10 ~ 38 ms** | |

社区对照数据：Mirage 项目 2880x1800@60fps 实测端到端 **中位 19ms，p95 27ms**。

这说明 **20ms 左右是可达到的目标**，跟物理显示器相比只差一到两帧。

## 复现方式

```bash
cd prototype/mac

# 虚拟屏生命周期
swiftc -O Sources/VirtualDisplay.swift Sources/main.swift -o vdtest
./vdtest 2560 1600 2560 1600 60 3

# 编码性能
swiftc -O EncodeBench2.swift -o encodebench2
./encodebench2 2560 1600 5 80

# 采集性能
swiftc -O CaptureBench2.swift -o capturebench2
./capturebench2 6

# 抓一帧验证内容
swiftc -O CaptureDump.swift -o capturedump
./capturedump && open /tmp/vd_sck.png
```
