# 针对 RESULT-2026-11-08 的处理说明

对应 Windows 端实测反馈。NV12 那部分已由 `51bc2cb` 修好并实测通过，
这里只补充**「静止画面不出帧」的真实根因**——它不在 Windows 端，也不在 ScreenCaptureKit。

---

## 结论先行

之前判断「ScreenCaptureKit 抓虚拟屏，没有内容变化就不出帧」是错的。

真实原因是 Mac 发送端存在**连接状态竞争**：新连接建立后，被上一次连接遗留的异步回调
立刻标记为断开，于是 `send()` 在入口直接返回，既不发送也不计丢帧。

这对每个新连接都成立，所以用纯 Python 客户端重连同样是 0 帧。

---

## 证据

Windows 侧看到的现象：连上后收包停在 9 或 1，之后 `0.0 Mbps`。

同期 Mac 端日志：

```
[9069.924] 采集 5726  编码 5726  关键帧 24  发送 1  丢弃 30  0.0 Mbps  目标 180  在途 0
[9071.922] 采集 5769  编码 5769  关键帧 24  发送 0  丢弃 30  0.0 Mbps  目标 180  在途 0
[9073.923] 采集 5793  编码 5793  关键帧 24  发送 0  丢弃 30  0.0 Mbps  目标 180  在途 0
```

关键三个数字：

- `采集/编码` 一直在涨 —— 抓屏和编码是正常的
- `发送 0`、`丢弃 30` 都停住 —— `send()` 既没发也没丢，说明卡在入口 guard
- `在途 0` —— 不是拥塞

`send()` 的入口是 `guard connected, let c = conn else { return }`，
所以只能是 `connected == false`。

## 根因代码

```swift
self.conn?.cancel()      // 取消旧连接
self.conn = c
self.connected = true    // 新连接标记已连接
```

`cancel()` 之后，旧连接的 `stateUpdateHandler` 会**异步**回调 `.cancelled`，
而那个闭包捕获的是同一个 `self`，于是把刚设好的 `connected` 又改回 `false`。

时序：

```
t0  accept 新连接 → conn = new, connected = true
t1  旧连接的 .cancelled 回调到达 → connected = false   ← 新连接被误杀
t2  编码线程调用 send() → guard 失败 → 静默返回
```

---

## 修复（Mac 端，commit 已推送）

### 1. 连接代数

给每条连接一个自增编号，回调里先比对编号，陈旧连接的回调直接忽略：

```swift
self.connEpoch &+= 1
let epoch = self.connEpoch
...
c.stateUpdateHandler = { [weak self] st in
    guard let self, self.connEpoch == epoch else { return }   // 陈旧连接，忽略
    ...
}
```

`receiveLoop` 也带上代数，避免旧连接的读回调继续影响新连接。

### 2. 复位在途帧计数

旧连接被重置时，未完成的 `send` 完成回调可能不再触发，`inFlight` 会永久停在 2，
此后所有帧都被当成拥塞丢掉。

新连接建立时清零：

```swift
func resetInFlight() {
    counterLock.lock(); inFlight = 0; counterLock.unlock()
}
```

### 3. 静默保活（顺带加的保险）

即使画面真的完全静止（无光标移动、无时钟变化），也保证码流不中断：

- 记住最近一帧的像素缓冲
- 超过 1 秒没有新帧，就重新编码一次同一帧
- 内容相同，编码出来是很小的 P 帧，带宽可忽略

### 4. 编码 PTS 改为内部自增序号

采集帧和保活帧的时间基准不同，混用会让 PTS 非单调，编码器可能拒绝。
端到端时间戳走包头里的 `captureTimeMicros`，与 PTS 无关。

## 复测要点

1. 连接后 `包` 计数应持续增长，不再停在个位数
2. `丢弃` 应保持 0 或很小
3. 静止画面下每秒至少约 1 帧（保活）
4. Windows 端 `解码失败` 保持 0
5. 画面比例正常（若被压扁，说明 `StreamSourceRect` 裁剪没生效）
